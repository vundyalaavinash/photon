Command blocks

Each command and its output grouped, with a red edge on failure. Click a block to copy it, re-run it, or hand it to an agent.

2

Folder chip

Click to jump to another folder (recent folders, fuzzy search). Runs cd for you.

3

Git branch chip

Click to switch or create a branch from a list, no typing git checkout.

4

Editor-style input

The command line is a real text box: mouse to move the cursor, multi-line, select and delete like in an editor.
