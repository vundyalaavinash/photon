A

Fix a failed block with your agent

One click hands the failure to Claude Code / Devin (your subscription). Fix goes back into the same terminal.

B

Test & build blocks

Pass/fail summary, clickable file:line (opens in a split), re-run only the failed tests, "what changed vs last run".

C

Git blocks you can act on

git status with stage/diff buttons, git log with clickable commits, AI commit message.

D

Long-running blocks

Dev servers stay a live block: open-URL chip, stop button, collapse noise, pin. Mac notification when a slow command finishes or a server errors.

E

Tables & JSON

kubectl, ps, docker ps output becomes a sortable/filterable table; JSON gets a fold-able tree.

F

Agent commands as blocks

Anything an agent runs shows up as a normal block with Allow / Edit / Deny, and risky commands (force push, rm -rf) get a warning.

G

Type in plain English

Start the line with # ("# undo my last commit but keep changes") and your agent proposes the command for you to run.

H

Find & history

Search inside one block's output, sticky command header while scrolling, history search across all projects (with exit codes and folder).

Things reviewers hated in Warp that Photon avoids by design: forced sign-in, 1 GB+ memory, AI reading the terminal without asking, interactive programs (top, ssh) breaking blocks. AI here only runs when you click it.
